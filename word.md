Projet #1- Conception d’un site Web,  hiver 2024
 
L’objectif de ce projet est de mettre en place une plateforme en ligne qui permet de fournir des informations une université, ses programmes, ses services, ses étudiants, son corps enseignant et son personnel administratif. Elle vise à faciliter la connectivité entre les étudiants actuels et anciens de l’école ou de l’université, favoriser la collaboration, l'échange de connaissances et le réseautage, etc.

Ce site web vise à promouvoir l’école ou l’université à un public plus large.

Critères à respecter 
Vous devez respecter les critères suivants dans le cadre de conception de votre site Web : 
•	Vos fichiers html et CSS doivent être zippés dans un dossier de format zip
•	Le regroupement des pages dans un menu
•	Le site Web doit contenir au moins une liste non-ordonnée et une liste ordonnée (la liste pour le menu ne compte pas)
•	Une page doit contenir des liens internes
•	Le site doit contenir au moins deux tableaux
•	Le site doit contenir au moins 3 images

Critères à respecter pour le code source
Le code source doit respecter les critères suivants : 
•	Le code HTML doit être indenté
•	Le code CSS doit être dans un ou plusieurs fichiers séparés
•	Les balises doivent être en minuscules
•	Les propriétés CSS doivent être en minuscules;


Livrable à soumettre
Vous aurez à soumettre sur OMNIVOX un dossier compressé de FORMAT ZIP contenant tous les fichiers du site Web (clic droit----->envoyer vers---->dossier compressé). 
•	Seul le format ZIP sera accepté et corrigé
•	Le nom du dossier sera appelé ainsi : NomGroupe-nom de famille de chaque membre
•	Exemple : Béthel-Trude-Levesque-Nkambou
•	Important : La composition de l’équipe (nom de famille, prénom) doit être listée dans un fichier Word. 
•	NB : Chaque équipe doit comporter 2 à 3 personnes.
